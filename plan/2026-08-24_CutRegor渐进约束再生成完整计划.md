# CutRegor 渐进式对称破缺约束再生成完整计划

状态：核心假设已证伪，按预注册门槛停止；未进入 branch-and-contract。
轨道：默认无新增训练的严格 pairwise REGOR。
在线终点：当前 source/target 点云与冻结 PREDATOR 特征 → 唯一 `4×4` 刚体变换。

## 目标

实现 CutRegor：维护多个局部 SE(3) 位姿单元，估计竞争位姿诱导的 target 部分自对称支持域，在其边界生成四锚点 bridge correspondence 域，再以 partial bijection、patch adjacency 和位姿区间约束逐轮收缩可行位姿集合；最后对唯一最佳位姿运行原生 REGOR densification 和 estimator。

## 新增机制

相对历史新增项限定为：

1. **表示**：竞争 mode 诱导的 target 部分自对称支持域及其图边界；
2. **动作空间**：由当前 mode pair 动态产生、覆盖未区分 mode pair 的 frontier query；
3. **候选**：由四个跨区域 anchor 薄球壳交集产生的 set-valued bridge correspondence；
4. **状态**：局部 Lie-algebra pose cell，而不是单 pose 分数；
5. **推断约束**：bridge domain、partial bijection、patch adjacency 与 interval residual 的 branch-and-contract。

如果 frontier 不能产生比随机区域更高的 exclusive bridge separation，则“新增表示能提供判别信息”的前提失败，CutRegor 不得继续包装为新观测。

## 论文依据与性质

- REGOR：progressive correspondence regeneration；
- MAC：多个 maximal-clique pose hypothesis；
- 4PCS：跨区域四点刚体不变量与全局 pose birth；
- ROBIN：由刚体不变量构造兼容图；
- complete rigid-pattern invariants：高阶有限几何关系比单点表面接近更有表达力。

CutRegor 的 symmetry frontier、bridge regeneration 和 pose-set contraction 是项目原创探索性组合，不是上述论文的严格复现，也没有论文结果保证 3DLoMatch 有效。

## 输入与 GT 隔离

### 在线输入

- `output/regor/2026-08-15_Hard247OnlineArtifacts/` 或同 schema 的完整 1781 去标签 artifact；
- 当前 pair 的 sampled XYZ、冻结 PREDATOR feature 和确定性随机状态；
- 由当前 pair 重新生成的 correspondence、pose、patch graph 和 bridge constraint。

### Frontier Test 特殊边界

Frontier Test 是离线容量诊断：在线 runner 只生成候选和去标签几何 trace；独立 analyzer 才读取 baseline GT trace，选择一个 GT-near mode 与最高 FS-TCD hard-negative mode并计算分离率。该结果不得称为在线 selector 或端到端方法。

### 正式 CutRegor

正式 runner 不读取 baseline trace 中的 `gt_trans`，不接收 GT-near mode ID。全部 mode 必须由当前 pair 在线出生并接受统一 branch-and-contract。

## 冻结 Frontier Separability Test

### 数据

hard 247 全集，仅作开发诊断。样本必须同时存在至少一个成功 refined candidate 和至少一个失败候选；其他样本按不可观测记录，不从分母静默删除。

### 几何配置

- 从 sampled cloud 以确定性 FPS 选 384 个 patch center；
- 分辨率 `delta=medianNN(source∪target)`；
- patch 尺度固定为 `4δ/8δ/16δ`；
- partial-symmetry 支持要求位置误差 `≤2.5δ`、法向误差 `≤0.25`、归一化协方差谱 L1 `≤0.35`、邻接长度误差 `≤2.5δ`；
- multi-scale 支持要求三个尺度至少两个通过；
- 每种 query 固定最多 32 个；
- bridge 固定 4 个跨空间 anchor、球壳容差 `2.5δ`、每个 domain 最多 8 个 target 点；
- query 对比：random、high-curvature、high-disagreement、symmetry-frontier。

### 预注册继续条件

- frontier separation rate 比 random 高至少 15 个百分点；
- GT-near mode bridge survival 高于 90%；
- multi-scale frontier 优于单尺度 frontier；
- 四锚点优于单点局部域。

以上全部满足才把 branch-and-contract 作为同一计划的下一阶段。失败则停止 CutRegor 的 symmetry-frontier bridge family；不扫描阈值或换 query 数。

## 执行结果

正式结果：`output/regor/2026-08-24_CutRegorFrontier_G17_Hard247_v2/frontier_summary.json`。候选输入为物理脱敏的 G17 当前-pair 多模式池，共 247 对；其中 201 对具有 GT-near member 和不同的错误代表 mode，可进入诊断，46 对按不可观测保留，0 error。

| 指标 | random | symmetry-frontier | 预注册要求 | 判断 |
|---|---:|---:|---:|---|
| separation rate | 12.61% | 16.60% | frontier 至少高 15 个百分点 | 仅高 3.99 个百分点，失败 |
| GT-near bridge survival | 23.07% | 75.28% | >90% | 失败 |
| 多尺度 separation | — | 16.60% | 高于单尺度 | 单尺度 16.72%，失败 |
| 四锚点 separation | — | 16.60% | 高于单点 | 单点 3.54%，通过 |

Reviewer 修正了初版中的两处不忠实实现后才产生上述正式结果：partial symmetry 使用 target 点到平面误差；四锚点用局部坐标下降直接最大化四面体矩阵最小奇异值。修正后的 4 个单元测试全部通过。

## 证伪机制与未解释现象

- 被证伪机制：`mode pair → partial symmetry → frontier → exclusive bridge` 不能在 hard247 上形成足够强的独占约束；frontier 的正负 domain 同时存活，增益远低于 15 个百分点。
- 阶段证据：四锚点确实比单点更能阻止错误 mode，但同时把正确 mode survival 压到 75.28%，不足以支持安全 pose-cell 删除。
- 未解释现象：单尺度略高于多尺度 0.12 个百分点；当前证据不能判断这是 patch 统计噪声还是多尺度支持定义本身没有增量信息，但预注册规则禁止继续扫描阈值和尺度投票。
- 终点：没有合法理由继续实现 AC-3、区间分裂和 rigid patch cover；这些后端无法补回前端没有产生的排他约束。
